<objective>
Train, tune, and ensemble GPU-accelerated pixel-level segmentation classifiers on binary fold1 features, evaluate on Fold 2, optimize ensemble weights, and persist all artifacts.

**Training Flow:**
1. Load `fold1_binary_X_scaled.npy` → slice to 25 RFE columns
2. Run Optuna HPO (200K subsample) per model → get best_params per model
3. Refit each model on full Fold 1 with best_params
4. Scale Fold 2 in-memory via loaded scaler → slice to 25 RFE cols
5. Get predict_proba from each model on Fold 2
6. Grid search weight simplex → optimal weights → serialize ensemble
7. Run inspection notebook

**Infrastructure already in place (Phase 3 committed):**
- `data/processed/fold1_binary_X_scaled.npy` — ready to slice
- `data/models/scaler_fold1_binary.joblib` — for Fold 2 transform
- `data/models/selected_features_rfe_25.json` — feature indices
- `src/training/scaler.py`, `src/utils/safe_loader.py`
</objective>
