# Plan 04-01 Summary: Binary Segmentation Ensemble Training

## What Was Built

### `src/training/ensemble.py` (284 LOC)
Core ensemble module implementing:
- **`SoftVotingEnsemble`** class with `fit()`, `predict_proba()`, `predict()`, `optimize_weights()`, `save()`, and `classmethod load()`.
- **`build_default_estimators(rf_params, lgbm_params, xgb_params)`** factory that returns `{rf: cuMLRF, lgbm: LGBMClassifier, xgb: XGBClassifier}` with `random_state=42` — falls back to sklearn RF when cuML is unavailable.
- Weight simplex grid search (`SIMPLEX_STEP=0.1`, ~165 combinations) that maximises Macro-F1 on Fold 2 held-out validation.
- All shape assertions at every public method boundary (`assert X.ndim == 2`, `assert y.ndim == 1`, `assert X.shape[1] == 25`).
- cuML import guard: `try: from cuml.ensemble import RandomForestClassifier as CuMLRF; HAS_CUML = True except ImportError: from sklearn.ensemble...`

### `scripts/train_ensemble.py` (≈442 LOC)
Full training CLI pipeline:
- `argparse` interface with `--fold`, `--selected-features`, `--out-dir`, `--n-trials`, `--hpo-sample-n`, `--optuna-timeout`.
- Loads `fold1_binary_X_scaled.npy` via `safe_load_npy(mode="r")` and slices to 25 RFE columns before loading into RAM.
- Draws 200K stratified subsample → 80/20 HPO split via `StratifiedShuffleSplit`.
- Three independent Optuna studies (`rf_study`, `lgbm_study`, `xgb_study`) with TPE sampler.
- Fold 2 scaled in-memory in 50K-row chunks via `FeatureScaler.load(...)`._scaler.transform() — no new `.npy` written.
- Weight simplex optimisation on Fold 2 predictions.
- Saves: `cuml_rf.joblib`, `lgbm.joblib`, `xgboost.joblib`, `binary_ensemble.joblib`, plus 3 JSON param files.
- RSS telemetry printed at every major step via `psutil`.

### `tests/test_ensemble.py` (9 tests)
CPU-only pytest suite — no GPU required:
1. `test_predict_proba_shape` — verifies `(500, 2)` shape output
2. `test_predict_values` — confirms `{0, 1}` values only, length 500
3. `test_weighted_average_math` — manually verifies weighted blend against known constant probas
4. `test_equal_weights` — confirms equal weights → simple mean
5. `test_optimize_weights_sums_to_one` — coarse step=0.5 grid, result sums to 1.0
6. `test_save_load_roundtrip` — save to tempdir, load, predict — identical results
7. `test_shape_assertion_X` — 1-D input raises `AssertionError`
8. `test_shape_assertion_y` — 2-D y raises `AssertionError`
9. `test_cpu_fallback` — patches `HAS_CUML=False`, verifies sklearn RF is used

### `notebooks/08_inspect_binary_ensemble.ipynb` (8 sections)
Research notebook generated by `notebooks/create_ensemble_notebook.py` via `nbformat`:
1. **Setup & Artifact Loading** — loads models, scales Fold 2 in-memory, prints model summary
2. **ROC & Precision-Recall Curves** — overlaid ROC + PR curves for all 4 classifiers with AUC-ROC and AP scores
3. **Confusion Matrix & Classification Report** — 4-panel heatmap + `classification_report` per model
4. **Feature Importance Comparison** — grouped bar chart of normalised RF/LGBM/XGB importances sorted by average
5. **Probability Calibration Curves** — reliability diagrams for all 4 models
6. **Weight Optimisation Surface** — 2D heatmap of Macro-F1 over simplex with ★ at optimal weights
7. **Per-Tissue F1 Breakdown** — falls back gracefully to class distribution when tissue metadata absent
8. **Decision Summary** — writes `DECISION.md` with final Fold 2 results and prints winner line

Notebook includes graceful missing-file guard: if training artifacts don't exist, it prints instructions and exits without crashing.
