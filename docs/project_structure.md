## Execution order (run scripts in this exact sequence)

```
1.  conda env create -f environment.yml
2.  python scripts/demo_streaming_pipeline.py      # verify data loads
3.  python scripts/fit_normalizer.py               # must run before feature extraction
4.  python scripts/build_training_data.py --mode binary
5.  python scripts/build_training_data.py --mode 3class
6.  python scripts/build_stage2_dataset.py
7.  python scripts/train_stage1.py --mode binary
8.  python scripts/train_stage1.py --mode 3class
9.  python scripts/train_stage2.py
10. python scripts/tune_stage1.py --mode binary --trials 50
11. python scripts/tune_stage1.py --mode 3class --trials 50
12. python scripts/train_stage1.py --mode binary   # retrain on best params
13. python scripts/train_stage1.py --mode 3class   # retrain on best params
14. python scripts/evaluate_stage1.py --mode binary --model rf
15. python scripts/evaluate_stage1.py --mode 3class --model rf
16. python scripts/evaluate_stage2.py --seg-model rf_stage1_binary_tuned
17. python scripts/evaluate_stage2.py --seg-model rf_stage1_3class_tuned
```

Steps 4–6 are the longest (feature extraction over ~6,000 images).
Steps 10–11 require 2 hours each with --trials 50.
All other steps complete in under 30 minutes each.

## Files that must never be edited after training begins

Once training data is built and models are saved, these files are frozen.
Changing them invalidates all saved models and requires full retraining.

| File | Why frozen |
|---|---|
| `src/features/pixel_feature_extractor.py` | TOTAL_FEATURES=91 is baked into selector and model input shape |
| `src/features/nucleus_feature_extractor.py` | N_NUCLEUS_FEATURES=46 is baked into Stage 2 model |
| `src/data/label_generator.py` | Label schema change = different targets = meaningless saved models |
| `src/preprocessing/color_converter.py` | Feature values depend on color conversion — change here = feature distribution shift |
| `data/models/normalizer.joblib` | Re-fitting on different reference image shifts all feature values |

## Files that are safe to regenerate at any time

| File/Folder | How to regenerate |
|---|---|
| `data/processed/*.npy` | Re-run build_training_data.py and build_stage2_dataset.py |
| `data/debug_samples/` | Re-run demo_streaming_pipeline.py or verify blocks in guide |
| `data/models/*.joblib` | Re-run corresponding train_*.py script |
| Any notebook output | Re-run notebook cells in order |
